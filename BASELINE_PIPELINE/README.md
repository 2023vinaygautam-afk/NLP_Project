# Baseline NLP Pipeline

The Streamlit app's **Evaluation Results** page displays the official
five-query baseline-versus-adaptive comparison generated by
`MAIN_ADAPTIVE_PIPELINE\experiments\baseline_vs_adaptive.py`.

The shared protocol uses multi-document relevance labels and reports macro
set-based Precision, Recall, and F1 over all retrieved documents. The app reads
the shared report from the sibling `MAIN_ADAPTIVE_PIPELINE\results` directory.
Older evaluation scripts and output files remain available for reference but
are not displayed as official results.
